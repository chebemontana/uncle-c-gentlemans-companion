UNCLE C — GENTLEMAN'S COMPANION
================================

This package is an Android-ready web ebook companion.

Included:
- Fresh Black Gentleman's Handbook PDF
- Generated cover and visual gallery
- Glossy emerald/olive/gold interface
- Curated links to the four reference books
- Personal signature style and routine

IMPORTANT COPYRIGHT NOTE
The four external books are NOT reproduced inside this package. Their cards link to publisher/catalog/legitimate access pages. This avoids redistributing copyrighted books without permission.

ANDROID INSTALLATION
1. Open index.html in a browser for immediate use.
2. For a true APK, open this project in Android Studio and wrap the web app in a WebView or use a trusted WebView/PWA packaging workflow.
3. The package is intentionally kept as a self-contained web app so it can be tested before producing a signed APK.
